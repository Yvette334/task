# Task Management Dashboard

A responsive and interactive task management dashboard built with HTML5, JavaScript, and Tailwind CSS.

## Features

### Requirements
- **Initial Sample Tasks**: 5 predefined tasks with different statuses
- **Add New Tasks**: Form with task name and due date validation
- **Edit Tasks**: Modal form to update task details
- **Delete Tasks**: With confirmation dialog
- **Mark Complete/Incomplete**: Toggle task status with visual feedback
- **Responsive Design**: Works on desktop, tablet, and mobile

### Additional Features
- **Task Filtering**: View All, Pending, or Completed tasks
- **Task Sorting**: Sort by due date, name, or status
- **Local Storage**: Tasks persist after page refresh
- **Animations**: transitions and notifications

## Technologies Used

- **HTML5**: Semantic structure and accessibility
- **JavaScript**: DOM manipulation and task logic
- **Tailwind CSS**: Responsive styling and utilities
- **LocalStorage**: Data persistence
